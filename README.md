# lifeboard

lifeboard is a personal dashboard I built for my own use. It runs only on
my own Windows PC and is not offered to anyone else.

It connects to my Google account to show my own Google Calendar events.

## Privacy

- lifeboard asks Google only for read-only access to my calendar
  (`calendar.readonly`). It never creates, changes or deletes events.
- Everything it reads stays on my own PC. Nothing is sent to anyone else,
  sold or shared.
- The sign-in token is stored encrypted on my PC and never leaves it.
- Access can be removed at any time at
  https://myaccount.google.com/permissions.
